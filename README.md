# thenarrativeforgery.github.io

Public interactive archive for **The Narrative Forgery**.

**Live URL:** https://thenarrativeforgery.github.io/

## Deploy

1. Upload the full mobile `index.html` to the root of this repo (replace any placeholder).
2. **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/ (root)**
3. Wait 1–2 minutes, then open the live URL.

Private working copy remains at `thenarrativeforgery/TNF_site`.
